## ۱. میز سیگنال چیست

میز سیگنال یک برنامه‌ی تحت وب (PWA) برای کار با سیگنال‌های یک کانال تلگرام کریپتو است (پیش‌فرض: `@ccoineres`).
روی گوشی مثل یک اپ نصب می‌شود و این کارها را می‌کند:

- **می‌خواند:** پست‌های کانال را از صفحه‌ی عمومی تلگرام می‌گیرد و سیگنال‌ها (نماد، جهت، ورود، استاپ، تارگت) را تشخیص می‌دهد.
- **حساب می‌کند:** حجم، مارجین، اهرم امن در مارجین ایزوله، قیمت لیکوئید و R هر تارگت را بر اساس ریسک خودت.
- **نگه می‌دارد:** پوزیشن‌هایی که گرفته‌ای را با قیمت زنده دنبال می‌کند، نقشه‌ی خروج پله‌ای می‌دهد و هشدار می‌دهد.
- **می‌سنجد:** «کانال‌سنج» هر سیگنال کانال را با کندل واقعی بازار جلو می‌برد تا معلوم شود واقعاً چه شده (برد، باخت، فعال نشد، در جریان).
- **پیشنهاد می‌دهد:** «بازار» (رادار) خودش بازار را بررسی می‌کند، فرصت‌ها را با ستاره و دلیل نشان می‌دهد و می‌گذارد آن‌ها را آزمایشی (بی پول) تست کنی.
- **کارنامه می‌سازد:** سود و ضرر روزانه، ماهانه و کل، رفتار، تخلف از قاعده‌ها و مقایسه‌ی تو با کانال.

**اصل‌های برنامه:**

- **بی‌سرور:** همه‌ی محاسبه‌ها و داده‌ها داخل مرورگر خودت است. چیزی به سرور ما فرستاده نمی‌شود (سروری نداریم).
- **ورکر اختیاری:** فقط اگر بخواهی، یک «ورکر» رایگان روی Cloudflare راه می‌اندازی که سه کار می‌کند: واسط اتصال (عبور از فیلتر)، همگام‌سازی بین دستگاه‌ها، و هشدار تلگرام وقتی برنامه بسته است. ورکر مال خودت است.
- **به صرافی وصل نمی‌شود:** برنامه هیچ سفارشی در صرافی نمی‌گذارد و کلید API نمی‌خواهد. معامله را خودت در صرافی می‌زنی و در برنامه ثبت می‌کنی.
- **عدد انگلیسی، متن فارسی:** همه‌ی عددها با رقم انگلیسی نشان داده می‌شوند تا با صرافی یکی باشند.

## ۲. شرایط، نیازمندی‌ها و هشدارها

### نیازمندی‌ها

| چیز | لازم است؟ | توضیح |
|---|---|---|
| گوشی یا کامپیوتر با مرورگر تازه | بله | کروم یا اج (اندروید/ویندوز/مک)، سافاری (آیفون، iOS 16.4 به بالا برای اعلان). |
| اینترنت | بله | برای خواندن کانال و قیمت‌ها. بدون اینترنت برنامه باز می‌شود و داده‌ی ذخیره‌شده را نشان می‌دهد. |
| فیلترشکن یا واسط شخصی | در ایران معمولاً بله | t.me و بعضی صرافی‌ها در ایران بسته‌اند. یا فیلترشکن روشن باشد، یا ورکر کلودفلر (بخش ۳.۴). |
| جایی برای میزبانی فایل‌ها | برای نصب روی گوشی | GitHub Pages، Cloudflare Pages یا هر هاست ایستا (بخش ۳.۱). |
| حساب رایگان Cloudflare | اختیاری | برای واسط شخصی، همگام‌سازی و هشدار تلگرام. |
| ربات تلگرام | اختیاری | فقط برای هشدار تلگرام وقتی برنامه بسته است. |
| Node.js 22 و git | فقط برای توسعه | ساختن `index.html` از `src/` و اجرای تست‌ها. برای استفاده‌ی معمولی لازم نیست. |

### شرایط استفاده و هشدارها

- **این برنامه توصیه‌ی مالی نیست.** ابزار کمک‌تصمیم و حساب‌وکتاب است. ستاره‌ها، «قابل گرفتن» و «قاعده‌ی پول واقعی» از روی داده‌ی گذشته ساخته شده‌اند و آینده را تضمین نمی‌کنند.
- **معامله با اهرم پرریسک است.** ممکن است کل مارجین را از دست بدهی. فقط با پولی کار کن که از دست دادنش زندگی‌ات را به هم نمی‌ریزد.
- **مسئولیت هر معامله با خودت است.** برنامه سفارش نمی‌گذارد؛ عددها را قبل از زدن در صرافی خودت چک کن (مخصوصاً نماد، جهت، استاپ و اهرم).
- **داده‌ها روی دستگاه خودت است.** اگر داده‌ی مرورگر را پاک کنی یا گوشی را عوض کنی و پشتیبان نداشته باشی، پوزیشن‌ها و کارنامه از بین می‌رود. پشتیبان بگیر (بخش ۱۶).
- **سنجش کانال تخمین است.** با کندل ۵ دقیقه‌ای (و در ابهام ۱ دقیقه‌ای) حساب می‌شود؛ ترتیب دقیق رویدادها داخل یک کندل همیشه معلوم نیست و برنامه محتاطانه فرض می‌کند.
- **قیمت‌ها از صرافی‌های عمومی می‌آیند** (بایننس، MEXC، Gate، KuCoin، Bitget، OKX). اگر صرافی تو قیمت دیگری دارد، کمی فرق طبیعی است.
- **حریم خصوصی:** برنامه چیزی جمع نمی‌کند. ورکر هم فقط به میزبان‌های مشخص (تلگرام و صرافی‌ها) درخواست می‌فرستد و داده‌ی همگام‌سازی فقط با رمز خودت خوانده می‌شود.
- **فونت:** وزیرمتن با پروانه‌ی SIL OFL (فایل `fonts/OFL.txt`).

## ۳. نصب و راه‌اندازی

برنامه در اصل **یک فایل** است: `index.html`. کنارش چند فایل کمکی هست: `manifest.webmanifest` (برای نصب روی گوشی)،
`sw.js` (برای کار بدون اینترنت)، `fonts/` و `icons/`. همین پنج چیز را جایی بگذار که با `https://` باز شود، کافی است.

### ۳.۱ میزبانی (پیشنهادی): GitHub Pages

1. در گیت‌هاب یک مخزن بساز (یا همین مخزن `coin` را استفاده کن) و همه‌ی فایل‌های پروژه را در آن بگذار.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch** را بزن.
3. شاخه (مثلاً `main`) و پوشه‌ی `/ (root)` را انتخاب کن و **Save**.
4. چند دقیقه بعد آدرسی مثل `https://<نام‌کاربری>.github.io/<نام-مخزن>/` می‌دهد. همین آدرس برنامه است.

**جایگزین‌ها:**
- **Cloudflare Pages:** dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets → پوشه‌ی پروژه را بکش و رها کن.
- **هر هاست ایستا** (حتی هاست ایرانی): فایل‌ها را در `public_html` بگذار. اگر هاست ایرانی است، اتصال به تلگرام را با ورکر یا فیلترشکن حل کن.

> فقط این‌ها برای اجرا لازم است: `index.html`، `manifest.webmanifest`، `sw.js`، `fonts/`، `icons/`.
> پوشه‌های `src/`، `tests/`، `tools/`، `docs/`، `proxy/` و `backup/` برای کار برنامه لازم نیستند (ولی ضرری هم ندارند).

### ۳.۲ اجرا روی کامپیوتر بدون هاست

- ساده‌ترین: در پوشه‌ی پروژه بزن `python3 -m http.server 8000` و در مرورگر برو به `http://localhost:8000`.
- دوبار کلیک روی `index.html` هم باز می‌شود، ولی در آن حالت (`file://`) نصب و کار بدون اینترنت فعال نمی‌شود و بعضی مرورگرها درخواست‌ها را می‌بندند. برای استفاده‌ی واقعی میزبانی کن.

### ۳.۳ نصب روی گوشی

- **اندروید (کروم):** آدرس برنامه را باز کن → منوی ⋮ → **Add to Home screen / نصب برنامه**.
- **آیفون (سافاری):** آدرس را باز کن → دکمه‌ی اشتراک ⬆️ → **Add to Home Screen**. اعلان روی آیفون فقط وقتی کار می‌کند که از همین آیکون باز شود (iOS 16.4+).
- بعد از نصب، برنامه تمام‌صفحه باز می‌شود و میان‌بر آیکون (نگه‌داشتن آیکون) هم دارد: در انتظار، پوزیشن‌ها، کانال‌سنج، اعلان‌ها.

### ۳.۴ واسط شخصی روی Cloudflare (برای عبور از فیلتر)

واسط‌های عمومی مجانی‌اند ولی زود شلوغ یا فیلتر می‌شوند. واسط خودت این وابستگی را برمی‌دارد. حدود ۵ دقیقه:

1. در برنامه: **سایر › تنظیمات › اتصال به کانال** → دکمه‌ی **«کپی کد ورکر»** (یا محتوای فایل `proxy/worker.js` را کپی کن).
2. در **dash.cloudflare.com** وارد شو (ثبت‌نام رایگان است).
3. **Workers & Pages → Create → Start with Hello World! → Deploy**.
4. **Edit code** را بزن، همه‌ی کد پیش‌فرض را پاک کن، کد کپی‌شده را بچسبان و دوباره **Deploy**.
5. آدرسی که می‌دهد (مثل `https://<اسم>.<اکانت>.workers.dev`) را در کادر **«واسط شخصی»** بنویس، با `/?url={url}` در آخرش:
   `https://<اسم>.<اکانت>.workers.dev/?url={url}`
6. **«تست همین واسط»** را بزن.

- اگر `workers.dev` روی شبکه‌ات باز نشد: در همان ورکر **Settings → Domains & Routes** یک دامنه‌ی خودت را وصل کن و آن آدرس را بگذار.
- تا ۶ آدرس (هر خط یکی) قبول است و همه با هم امتحان می‌شوند.
- ورکر فقط به این میزبان‌ها درخواست می‌دهد: تلگرام (`t.me`، `telesco.pe`، `cdn-telegram.org`) و صرافی‌ها (بایننس، MEXC، Gate، OKX، KuCoin، Bitget)؛ پروکسی باز برای همه‌ی اینترنت نیست.
- **جایگزین PHP:** اگر هاست خارجیِ PHP داری، `proxy/tg.php` را در `public_html` بگذار و آدرس `https://<دامنه>/tg.php?url={url}` را بنویس. هاست ایرانی معمولاً خودش به t.me دسترسی ندارد.

### ۳.۵ همگام‌سازی بین دستگاه‌ها (اختیاری)

اگر برنامه را روی دو دستگاه داری (مثلاً گوشی و کامپیوتر) و می‌خواهی داده یکی باشد:

1. در کلودفلر: **Storage & Databases → KV → Create namespace** (اسمش مهم نیست).
2. در ورکر: **Settings → Bindings → Add → KV namespace**؛ اسم متغیر را دقیقاً **`STORE`** بگذار و همان namespace را انتخاب کن.
3. در ورکر: **Settings → Variables and Secrets → Add → Secret**؛ اسم **`SYNC_TOKEN`** و یک رمز طولانی و تصادفی.
4. در برنامه: **تنظیمات › همگام‌سازی بین دستگاه‌ها** → «آدرس ورکر» (فقط ریشه، بدون `?url=`) و «رمز همگام‌سازی» (همان SYNC_TOKEN).
5. روی دستگاه اول **«ارسال به سرور»**، روی دستگاه دوم **«دریافت از سرور»**. از آن به بعد خودکار و پوزیشن‌به‌پوزیشن ادغام می‌شود.

بدون SYNC_TOKEN هیچ‌کس نمی‌تواند داده را بخواند یا بنویسد. داده فقط روی ورکر خودت می‌ماند.

### ۳.۶ هشدار تلگرام وقتی برنامه بسته است (اختیاری)

مرورگر وقتی برنامه کاملاً بسته است چیزی اجرا نمی‌کند. ورکر این جای خالی را پر می‌کند: هر دقیقه پوزیشن‌های باز را با مارک پرایس می‌سنجد و
سر استاپ، نزدیکِ استاپ، لیکوئید، تارگتِ پله‌ی بعدیِ نقشه، پایان مهلت پوزیشن، سیگنال تازه‌ی کانال و گزارش هفتگی (جمعه‌ها ساعت ۱۸ تهران) پیام می‌دهد.

1. همگام‌سازی (۳.۵) باید روشن باشد.
2. در تلگرام به **@BotFather** پیام بده، `/newbot` بزن و توکنی که می‌دهد را بردار.
3. در ورکر: **Settings → Variables and Secrets** → Secret به نام **`TG_BOT_TOKEN`** با همان توکن.
4. در ورکر: **Settings → Triggers → Cron Triggers → Add** → `* * * * *` (هر دقیقه).
5. کد تازه‌ی `proxy/worker.js` را در ورکر بگذار و **Deploy** بزن.
6. به ربات خودت در تلگرام یک پیام بده (مثلاً `/start`)، بعد در برنامه **«وصل کردن تلگرام»** و برای امتحان **«پیام آزمایشی»**.

ورکر پوزیشن را عوض نمی‌کند و به صرافی کاری ندارد؛ بسته شدن را خود برنامه دفعه‌ی بعد که بازش کنی از روی کندل‌ها ثبت می‌کند.

### ۳.۷ به‌روزرسانی

- **برنامه:** فایل‌های تازه را جای قبلی بگذار (یا در گیت‌هاب push کن). برنامه‌ی نصب‌شده نسخه‌ی تازه را پشت صحنه می‌گیرد و دکمه‌ی **«نسخه‌ی تازه»** نشان می‌دهد؛ بی‌اجازه وسط کار عوض نمی‌شود. داده‌ها دست نمی‌خورند.
- **ورکر:** هر بار `proxy/worker.js` عوض شد، باید کدش را در کلودفلر جایگزین و **Deploy** کنی؛ خودکار عوض نمی‌شود.
- **برگشت به نسخه‌ی قبل:** پوشه‌ی `backup/` نسخه‌های قبلی را دارد (راهنمایش `backup/README.md`).

## ۴. اولین بار: تنظیمات پیشنهادی

برنامه را باز کن، **سایر › تنظیمات**:

1. **اتصال به کانال:** نام کانال (پیش‌فرض `ccoineres`)، بروزرسانی خودکار (مثلاً هر ۳ دقیقه)، و اگر لازم است واسط شخصی.
2. **اندازه و ریسک:**
   - **موجودی حساب:** کل پولی که برای این کار گذاشته‌ای (مبنای درصدها و حد ضرر روزانه).
   - **ریسک هر معامله ($):** حداکثر ضرر هر معامله اگر استاپ بخورد. برای شروع ۰٫۵ تا ۱ دلار.
   - **سقف اهرم:** ۱۰.
   - **بیشترین فاصله‌ی استاپ برای ایزوله:** ۱۵٪ (سیگنال با استاپ دورتر «بلندمدت» حساب می‌شود).
   - **کارمزد رفت‌وبرگشت:** همان صرافی خودت (پیش‌فرض مارکت ۰٫۱٪، Limit ۰٫۰۴٪).
   - **حد ضرر روزانه، سقف ریسک باز هم‌زمان، قفل بعد از باخت‌های پیاپی:** ترمزهای رفتاری؛ پیش‌فرض‌ها خوب‌اند.
3. **تقویم:** شمسی، میلادی یا هر دو.
4. **اعلان و پیشنهاد:** مشاور را روشن کن، صدا و ساعت سکوت را بگذار.
5. **امکانات:** هر بخشی را نمی‌خواهی خاموش کن؛ برنامه دقیقاً به حالت بدون آن برمی‌گردد.
6. اگر می‌خواهی یک برنامه‌ی منظم داشته باشی: تب **نقشه** → «شروع از امروز» → «یک‌جا بگذار» (تنظیمات پیشنهادی رادار را یک‌جا می‌گذارد).

## ۵. آشنایی با صفحه

**سربرگ (بالای صفحه):**
- نام کانال و **وضعیت اتصال** («آنلاین · الان»، «در حال بروزرسانی»، «قطع»). زدنش «وضعیت و عیب‌یابی» را باز می‌کند.
- **دایره‌ی شمارش معکوس** (مثلاً `5د`): تا بروزرسانی خودکار بعدی.
- **زنگوله:** مرکز اعلان و پیشنهادهای مشاور (عدد قرمز = خوانده‌نشده).
- **دکمه‌ی طلایی ↻:** همین الان کانال و قیمت‌ها را تازه کن.
- **نوار کارهای در حال انجام:** کارهای طولانی (سنجش کانال، بررسی بازار، دنبال کردن تست‌ها) با درصد، «توقف/ادامه» (⏸) و «لغو» (✕). زدن نوار به همان بخش می‌برد.

**نوار پایین:** **بازار · پوزیشن‌ها · سیگنال‌ها · نقشه · سایر**
- عدد روی هر تب: کار منتظر در آن بخش.
- **سایر:** کانال‌سنج، کارنامه، آموزش، تنظیمات.
- با روشن کردن **«حالت تمرکز»** (در سایر)، تب اول «امروز» می‌شود و «بازار» به سایر می‌رود.

**برگه‌ها (Sheet):** بیشتر کارها در برگه‌ای باز می‌شود که از پایین بالا می‌آید؛ با ✕ یا کشیدن به پایین بسته می‌شود.
**«برگرداندن»:** بیشتر کارهای پاک‌کردنی و تغییرات، یک پیام پایین صفحه با دکمه‌ی «برگرداندن» دارند.

## ۶. بازار (رادار)

رادار خودش بازار را بررسی می‌کند (ده‌ها ارز برتر؛ تعداد و بازه‌ی رتبه قابل تنظیم) و فرصت‌های لانگ/شورت را با امتیاز، ستاره و دلیل نشان می‌دهد.
مدلش از تاریخچه‌ی واقعی (تا یک سال) «یاد می‌گیرد» کدام عامل‌ها در گذشته جواب داده‌اند.

### زیرتب‌ها

| زیرتب | چیست |
|---|---|
| **سیگنال‌ها** | فرصت‌های الان: «قابل گرفتن» و «بی اعتبار کافی (فقط برای تست)». |
| **آزمایشی** | تست‌های بی‌پول: باز، منتظر Limit، بسته‌شده، با جمع R و دلار. |
| **کارنامه** | مدل چقدر درست گفته: نتیجه‌ی سنجش روی تاریخچه، به تفکیک جهت، امتیاز، حال بازار و نقشه‌ی خروج. |
| **دفتر** | تاریخچه‌ی تست‌ها و پیشنهادها (آرشیو روزانه). |

### هوای بازار

بالای صفحه یک «چراغ» لانگ/شورت از روی بیت‌کوین، کل بازار، دامیننس‌ها و جریان پول. اگر **«فیلتر خلاف هوا»** روشن باشد،
سیگنال‌های خلاف هوای بازار «قابل گرفتن» نمی‌شوند. «برگشت هوا» یعنی جهت هوا تازه عوض شده.

### کارت هر سیگنال

- **سربرگ:** نماد، لانگ/شورت، امتیاز (۰ تا ۱۰۰)، ستاره (۰ تا ۵)، «تازه» یا «سیگنال از N ساعت پیش».
- **حکم:** ✓ «قابل گرفتن» یا ✗ با دلیل (خلاف هوا، استاپ خیلی نزدیک، سابقه‌ی مطمئن ندارد، این جهت در کل زیان‌ده است، خلاف روند بیت‌کوین، سقف هم‌جهت پر است).
- **سه عدد اصلی:**
  - **ورود Limit:** قیمتِ بسته شدن کندل سیگنال. مهلت آن **تا ساعت …** و **زمان باقی‌مانده** («۱ ساعت و ۱۰ دقیقه مانده»؛ زیر نیم ساعت نارنجی، بعد «مهلت گذشت»). مهلت = شروع کندل سیگنال + ۱ ساعت + ۲ ساعت.
  - **استاپ** با درصد فاصله.
  - **خروج:** نقشه‌ی خروجی که مدل برای این جهت انتخاب کرده (مثلاً «همه در +0.5R»).
- **چک‌لیست ورود:** چند شرط ساده (روند، حجم، …) با ✓/✗.
- **💰 قاعده‌ی پول واقعی:** اگر هر پنج شرط برقرار باشد (قابل گرفتن، لانگ، هوا برای لانگ نه «نامناسب»، چک‌لیست دست‌کم ۳، استاپ ۲ تا ۸٪) نشان 💰 می‌گیرد. فقط این‌ها برای پول واقعی پیشنهاد می‌شوند.
- **جزئیات و دلیل‌ها:** دلیل‌های مدل، واگرایی، تغییر ستاره، حجم، زمان کامل.
- **دکمه‌ها:** **«تست»** (آزمایشی، بی پول)، **«ورود»** (پوزیشن واقعی با همان عددها)، اشتراک.

### تست (آزمایشی)

- با «تست»، معامله‌ی آزمایشی با همان قاعده باز می‌شود: اگر قیمت الان بهتر از Limit است همان لحظه پر می‌شود، وگرنه «منتظر ورود Limit» تا پایان مهلت.
- برنامه تست‌ها را با کندل ۵ دقیقه‌ای دنبال می‌کند (حتی وقتی برنامه بسته بوده) و با استاپ، تارگت یا سقف زمان می‌بندد.
- روی هر تست: **«اگر نگه داشته بودیم؟»** (اگر طبق نقشه نمی‌بستیم) و **«اگر خلافش را گرفته بودیم؟»** (همان معامله در جهت مخالف و برای همان مدت).
- **«خروجی برای بررسی»:** فایل JSON کامل تست‌ها (با مسیر قیمت) برای تحلیل.

### تنظیمات رادار

- **افق:** کوتاه (تا ۲۴ ساعت)، **بلند (تا ۳ روز، پیشنهادی)**، هفتگی (تا ۷ روز).
- **انتخاب ارز:** بازه‌ی رتبه، نمادهای دلخواه و واچ‌لیست.
- **یادگیری دوباره:** بعد از عوض کردن افق یا کارمزدها خودش شروع می‌شود (چند دقیقه؛ در نوار کارها).
- **بررسی خودکار:** با برنامه‌ی باز، رادار گاه‌به‌گاه خودش تازه می‌شود.

## ۷. پوزیشن‌ها

همه‌ی معامله‌های واقعی‌ات. فیلترها: **منتظر · باز · بسته · همه** («منتظر» = سفارش‌های تریگری که هنوز فعال نشده‌اند) و منبع **همه · کانال · خودم**.

### کارت پوزیشن

- **سربرگ:** نماد، کانال/خودم، لانگ/شورت، اهرم، وضعیت، سبک نقشه‌ی خروج.
- **سود/ضرر شناور** به دلار، **روی مارجین (٪)**، **R** و **قیمت الان** (مارک پرایس برای فیوچرز).
- **نردبان قیمت:** ورود، استاپ (دستگیره‌ی طلایی؛ بکش تا حد ضرر جابه‌جا شود، بعد تأیید)، لیکوئید، قیمت الان و تارگت‌ها.
  - تا **تارگت ۱** رد نشده فقط همان دیده می‌شود («تارگت ۱ از ۳»)؛ بعد از رد شدنش بقیه هم می‌آیند و تارگت ۱ کم‌رنگ و خط‌خورده می‌شود.
  - ناحیه‌ی بین ورود و استاپ قرمز است؛ وقتی استاپ از ورود جلوتر رفت سبز (سود قفل شده).
- **نقشه‌ی خروج:** پله‌ها (مثلاً ⅓ روی هر تارگت) با «انجام شد» و «رد کن»، و جابه‌جایی استاپ بعد از هر پله. «عوض کن» برای تغییر سبک.
- **کانال‌سنج:** اگر پوزیشن از سیگنال کانال است، وضعیت همان سیگنال در کانال‌سنج.
- **«اگر خلافش را گرفته بودیم؟»** برای همین پوزیشن.
- **دکمه‌ها:** **بستن** (قیمت لحظه + «چرا بستم»، و «فرم کامل» داخلش)، **بستن بخشی**، **افزودن حجم**، و منوی ⋯ (ویرایش، حذف، اشتراک تصویر، …).
- **تاریخچه‌ی پوزیشن:** همه‌ی رویدادها (جابه‌جایی استاپ، بستن بخشی، …).

### خودکارها و هشدارها

- **اجرای خودکار** (اگر روشن است): رسیدن به استاپ یا پله‌ی نقشه را از روی کندل‌ها ثبت می‌کند.
- **ریسک‌فری خودکار** بعد از +X٪، **استاپ دنباله‌دار** X٪، **سقف زمان** هر پوزیشن (از تنظیمات).
- **هشدارها:** نزدیکِ استاپ، لیکوئید پیش از استاپ، پوزیشن‌های هم‌جهت زیاد، تخلف از نقشه، پیگیری‌های کانال («ریسک‌فری کنید»، «سیو سود»).
- **لغزش، کارمزد و فاندینگ** در سود و ضرر حساب می‌شوند.

## ۸. سیگنال‌ها

پست‌های کانال، دسته‌بندی‌شده.

### نوار فیلتر

| فیلتر | چیست |
|---|---|
| **الان چه کنم؟** | همه‌ی سیگنال‌های قابل گرفتن با دکمه‌ی اقدام و حال بازار. |
| **در انتظار** | سیگنال‌های این چند روز که هنوز تصمیمشان را نگرفته‌ای. |
| **همه** | سیگنال‌ها و نتیجه‌ها؛ خبر و اطلاع‌رسانی در آرشیو. |

و سطل‌های کنار: **نتایج** (پست‌های «تارگت خورد»، یادآوری‌ها)، **منقضی** (سیگنال قدیمی‌تر از «عمر سیگنال»)، **آرشیو** (خبر، تبلیغ، یادداشت).
فیلترهای ریزتر: روز، نوع، دسته‌ی دلخواه، فقط ایزوله، و … (ذخیره می‌شوند).

### کارت سیگنال

متن پست، تصویر (با زدن بزرگ می‌شود)، عددهای خوانده‌شده (ورود، استاپ، تارگت‌ها، اهرم کانال)، اسپات/فیوچرز، وضعیت (باز، منقضی، گرفته شد، رد شد) و دکمه‌ها:

- **بررسی و ورود:** ماشین‌حساب کامل:
  - **ورود ایزوله:** با «ریسک هر معامله»، مارجین و اهرمی که ضرر در استاپ دقیقاً همان ریسک شود؛ **اهرم امن** که لیکوئید را آن سوی استاپ نگه می‌دارد.
  - **دروازه‌ی ریسک:** اگر ریسک باز هم‌زمان یا حد ضرر روزانه پر است، هشدار می‌دهد.
  - **دیر رسیدی:** اگر قیمت از ورود جلو رفته، می‌گوید چقدر و R جدید چه شده.
  - **ورود پله‌ای**، **کپی برای صرافی** (همه‌ی عددها برای چسباندن)، **تریگر با بسته شدن کندل**.
- **منتظر …:** سفارش منتظر (تریگر) را در برنامه نگه می‌دارد و وقتی قیمت رسید خبر می‌دهد.
- **وارد نشدم:** با دلیل؛ در «شما در برابر کانال» شمرده می‌شود.
- **اصلاح دستی:** اگر برنامه نماد یا عددی را اشتباه خوانده، درستش کن (فقط برای همین پست).
- **سیگنال تصویری:** اگر عددها فقط روی چارت است، «عددها از روی چارت» را بزن و بنویس.

### خروجی متنی سیگنال‌ها

در تنظیمات: هر سیگنال یک خط (`TIME | TICKER | LONG/SHORT | … | LINK`) برای دادن به برنامه‌ی دیگر؛ کپی یا دانلود txt.

## ۹. نقشه (برنامه‌ی یک‌ماهه)

یک برنامه‌ی ۴ هفته‌ای برای اینکه با نظم بفهمی کانال و رادار به درد پول واقعی می‌خورند یا نه.

- **شروع:** «شروع از امروز»؛ نشان «هفته‌ی N» روی بازار هم می‌آید.
- **قانون‌های زنده (✓/✗):** تنظیمات قفل (افق بلند، خروج «همه در +0.5R»)، **حداکثر ۳ تست در روز**، **حداکثر ۳ تست هم‌جهت باز**، **اهرم ≤ ۱۰**. پیش از تست چهارم روز می‌پرسد.
- **هفته‌ها:**
  1. آماده‌سازی و سنجش کانال (تنظیمات پیشنهادی، کامل کردن سیگنال‌های ناقص کانال با نوار پیشرفت، سنجش دوباره، فرستادن فایل‌ها).
  2. آزمون قاعده‌ی کانال روی داده‌ی دست‌نخورده و تصمیم «کانال قبول/رد».
  3. اگر قبول: معامله‌ی واقعی کوچک (ریسک ۰٫۵ تا ۱ دلار، حداکثر ۳ پوزیشن)؛ اگر نه: فقط تست.
  4. داوری با معیار قبولی.
- **معیار قبولی** (برای کانال، تست‌ها و معامله‌های واقعی جدا): دست‌کم ۱۰۰ معامله، در دست‌کم ۳۰ روز، میانگین ≥ +0.1R بعد از کارمزد، ضریب سود ≥ ۱٫۳، مثبت در ≥ ۶۰٪ هفته‌ها، بیشترین افت ≤ 10R.

## ۱۰. امروز (حالت تمرکز)

با کلید «حالت تمرکز» در سایر، یک صفحه فقط برای تصمیم:
هوای بازار، سیگنال‌های کانالِ قابل گرفتن (بی خلاف هوا)، فرصت‌های رادار **هر کدام با زمان مانده‌ی ورود Limit** (زدنش کارت را در بازار نشان می‌دهد)،
پوزیشن‌های باز با سود/ضرر و مهلت، تست‌های بازار (با نزدیک‌ترین مهلت Limit) و نتیجه‌ی ۷ روز اخیر.

## ۱۱. کانال‌سنج

«کانال چقدر راست می‌گوید؟» هر سیگنال از لحظه‌ی دقیق انتشار با کندل واقعی جلو می‌رود. سنجش فقط وقتی خودت بزنی انجام می‌شود.

### دکمه‌های بالا

- **سنجش N سیگنال / سنجش تازه‌ها:** سیگنال‌های سنجیده‌نشده و «در جریان»هایی که بیش از ۲۰ دقیقه از سنجششان گذشته.
- **سنجش دوباره‌ی همه:** همه از نو.
- **قانون‌ها:** پایین‌تر.
- در **«وضعیت سنجش»:** «سنجیدن تازه‌ها و در جریان‌ها» (همه‌ی در جریان‌ها حتی همین الان سنجیده‌شده)، «آزمایش اتصال کندل»، «برگرداندن همه»ی کنارگذاشته‌ها، و زمان آخرین سنجش.

### وضعیت هر سیگنال

| وضعیت | معنی |
|---|---|
| **برد** | به تارگت اول رسید. |
| **باخت** | پیش از تارگت اول استاپ خورد. |
| **منقضی** | در مهلت نتیجه (پیش‌فرض ۳۰ روز) نه تارگت خورد نه استاپ؛ با قیمت آن لحظه حساب می‌شود. |
| **بسته (دستی)** | خودت در «در جریان» با قیمت الان بستی. |
| **فعال نشد** | قیمت به ورود نرسید (با دلیل: مستقیم به تارگت رفت / در مهلت به ورود نرسید / پیش از ورود از استاپ گذشت). |
| **در جریان** | وارد شده (یا منتظر ورود) و هنوز نتیجه ندارد. |
| **نیاز به بررسی** | عددی کم است یا جور نیست (نماد، ورود، استاپ، قیمت خیلی دور، تصویر بی‌عدد، کندل نیامد). |

### نوع ورود

قیمت لحظه‌ی انتشار با ورود کانال مقایسه می‌شود:
- **فوری:** فاصله تا «تحمل ورود» (پیش‌فرض ۱٪)؛ همان لحظه وارد.
- **منتظر برگشت به ورود:** قیمت از ورود جلوتر بوده؛ منتظر برگشت (حداکثر «مهلت ورود»، پیش‌فرض ۳ روز).
- **منتظر شکستن ورود:** قیمت پشت ورود بوده؛ منتظر عبور.
- **ورود بازار:** پست عدد ورود ندارد («ورود مجازه»)؛ ورود = قیمت لحظه‌ی انتشار.

### قانون‌ها

- **مهلت ورود** (روز)، **مهلت نتیجه** (روز)، **تحمل ورود** (٪).
- **در محدوده‌ی تحمل، ورود با:** «عدد اعلامی کانال» (به نفع کانال) یا **«قیمت بازار همان لحظه»** (R واقعی‌تر؛ عدد کانال کنارش نوشته می‌شود).
- **دکمه‌های آماده:** «ورود به‌موقع: تحمل ۳٪ با قیمت بازار (پیشنهادی)»، «تحمل ۲٪ با عدد کانال»، «پیش‌فرض (۱٪)». هر کدام سنجش را همان لحظه از نو شروع می‌کند.
- **امتیازدهی:** «همه در تارگت اول» یا «پله‌ای، استاپ به ورود بعد از تارگت اول».

### بخش‌ها (تاشو)

- **وضعیت سنجش:** چند پست، چندتا سیگنال، سنجیده، ناقص، دلیل‌ها و دکمه‌های کامل کردن.
- **فیلتر — «اگر فقط این‌ها را گرفته بودم؟»:** بک‌تست با فیلتر جهت، بازار، R:R، بازه، نماد، فقط ایزوله، بی‌دیرهنگام.
- **کارنامه‌ی کانال:** سنجیده، نرخ برد، مجموع و میانگین R، ضریب سود، باخت پیاپی، فعال نشد، در جریان، نیاز به بررسی؛
  «فعال نشد» به تفکیک دلیل با پیش‌نمایش «ورود به‌موقع»؛ بازه‌ی سنجش و **آمار هفته‌به‌هفته**؛ یادآوری‌های قدیمی جدا.
- **خروج: کدام قاعده بهتر جواب داده:** همان سیگنال‌ها با نقشه‌های خروج مختلف.
- **سرمایه و الگوها:** منحنی سرمایه با قاعده‌ی تو، بیشترین افت، به تفکیک ساعت انتشار، نوع ورود، ماه، حال بازار، زمان تا تارگت ۱.
- **همه‌ی سیگنال‌ها:** فهرست با چیپ‌های برد، باخت، فعال نشد، در جریان، نیاز به بررسی.

### فهرست «همه‌ی سیگنال‌ها» و کارهای هر ردیف

- **رنگ ردیف:** سبز = در سود (یا برد)، قرمز = در ضرر (یا باخت).
- **در جریان:** «الان قیمت · R · (٪ · دلار با ریسک هر معامله) · زنده · باز N روز و M ساعت». بالای فهرست جمع لحظه‌ای کل، چندتا در سود/ضرر و میانگین مدت باز بودن.
- **منتظر ورود:** فاصله تا ورود و مهلت.
- **فعال نشد:** دلیل، قیمت لحظه‌ی انتشار و فاصله‌اش با ورود، نوع انتظار.
- **دکمه‌ها:**
  - **تصویر:** تصویر و متن پست همان‌جا.
  - **جزئیات:** خط زمانی واقعی (انتشار، فعال شدن، تارگت‌ها، استاپ)، ادعاهای کانال درباره‌اش و ویرایش‌ها.
  - **اصلاح عددها:** برگه‌ی کانال‌سنج با عددهای فعلی، تصویر و قیمت لحظه‌ی انتشار. **ورود خالی = ورود همان لحظه.** اگر ورود بیش از ۳۰٪ با قیمت انتشار فاصله دارد ثبت نمی‌شود و عدد درست (یک صفر کم/زیاد) پیشنهاد می‌شود. بعد از ثبت همان سیگنال فوراً سنجیده می‌شود.
  - **ورود همان لحظه** (روی «فعال نشد»): با قیمت لحظه‌ی انتشار وارد حساب و فوراً سنجیده می‌شود.
  - **بستن با قیمت الان** (روی «در جریان»): اول تا همین لحظه سنجیده، بعد «بسته (دستی)» با همان R؛ «باز کردن دوباره» برمی‌گرداند.
  - **سیگنال نیست:** چارت یا پستی که فقط چون هشتگ داشت سیگنال حساب شد؛ از سیگنال‌ها و سنجش بیرون می‌رود (با برگرداندن).
- **مرور یکی‌یکی** (در «نیاز به بررسی»): سیگنال‌های ناقص یکی‌یکی با تصویر و نوار «N مانده». در هر کدام:
  «ثبت و بعدی»، «عدد ندارد؛ کنار بگذار»، «سیگنال نیست»، **«پست نتیجه است (سیگنال قدیمی)»**، **«درست است؛ با تاریخ اصلی بسنج»** (تاریخ سیگنال اصلی با تقویم میلادی یا دستی؛ شمسی زیرش نشان داده می‌شود).
- **برچسب‌ها:** دیرهنگام (تارگت پیش از انتشار خورده بود)، ورود دیر، ویرایش‌شده، حذف‌شده، ادعا ✓/✗، تارگت فرضی، از یادآوری.

### چرا کارنامه‌ی کانال بعد از هر سنجش عوض می‌شود؟

چون «در جریان»ها با هر سنجش تازه به برد یا باخت می‌رسند. وقتی تعداد «به نتیجه رسیده» کم است (مثلاً ۴ از ۹۶)، عددها هنوز قابل قضاوت نیستند.

## ۱۲. کارنامه

نتیجه‌ی معامله‌های **واقعی** خودت.

- **دوره:** روزانه، ماهانه، کل، بازه‌ی دلخواه. **تصویر بالا مال همان دوره است** («تصویر امروز»، «تصویر این ماه»، «تصویر کلی»).
- **منبع:** همه · کانال · خودم.
- **تصویر کلی:** خالص، کارمزد، تعداد، برد/باخت، نرخ برد، ضریب سود، میانگین R، میانگین هر معامله، میانگین برد/باخت، بهترین/بدترین، بازده حساب، نمودار سرمایه و بیشترین افت.
- **رفتار:** سود به ازای ساعت پول درگیر، کارمزد ماه، هدف ماهانه با نوار پیشرفت، نوار ۳۰ روز سبز/قرمز، خلاصه‌ی هفتگی، تخلف‌ها.
- **دفتر معامله:** ستاپ، حال روحی و «چرا بستم» هر معامله و اینکه کدام برایت پول ساخته.
- **شما در برابر کانال** و **در برابر قاعده‌ی من.**
- **کارت تصویری** برای اشتراک نتیجه (قابل ویرایش).

> اگر یک عدد غیرعادی دیدی (مثلاً یک معامله با سود چند برابر حساب)، معمولاً قیمت خروج یا حجم اشتباه ثبت شده؛ در پوزیشن‌ها › بسته درستش کن.

## ۱۶. داده‌ها، پشتیبان و همگام‌سازی

- **کجا ذخیره می‌شود:** حافظه‌ی مرورگر (localStorage، با درخواست «حافظه‌ی ماندگار» تا مرورگر خودش پاکش نکند).
- **پشتیبان JSON:** تنظیمات › داده‌ها › «پشتیبان JSON». همه‌چیز (پوزیشن‌ها، تنظیمات، اصلاح‌ها، آموزش‌ها، …). برنامه اگر مدتی پشتیبان نگرفته باشی یادآوری می‌کند.
- **بازیابی:** «بازیابی» و انتخاب فایل JSON.
- **CSV:** خروجی جدولی پوزیشن‌ها برای اکسل. کانال‌سنج هم CSV خودش را دارد.
- **خروجی تست‌ها:** بازار › آزمایشی › «خروجی برای بررسی».
- **همگام‌سازی:** بخش ۳.۵. ادغام پوزیشن‌به‌پوزیشن است؛ تغییر هم‌زمان روی دو دستگاه گم نمی‌شود.
- **هشدار:** پاک کردن داده‌ی مرورگر/سایت یعنی پاک شدن همه‌چیز. پیش از تعویض گوشی یا پاک‌سازی، پشتیبان بگیر.

## ۱۷. واژه‌نامه

| واژه | معنی |
|---|---|
| **R** | واحد ریسک: فاصله‌ی ورود تا استاپ. +1R یعنی به اندازه‌ی ریسک سود، −1R یعنی استاپ خورده. |
| **ریسک هر معامله** | دلاری که اگر استاپ بخورد از دست می‌دهی. دلار هر R. |
| **ایزوله / کراس** | ایزوله: فقط مارجین همان پوزیشن در خطر است. کراس: کل حساب پشت پوزیشن است. |
| **اهرم امن** | بیشترین اهرمی که در ایزوله لیکوئید را (با ۱۰٪ حاشیه) آن سوی استاپ نگه می‌دارد. |
| **لیکوئید** | قیمتی که صرافی پوزیشن را به زور می‌بندد. باید پشت استاپ باشد. |
| **Limit / Market** | Limit: سفارش با قیمت مشخص (کارمزد میکر، کمتر). Market: همان لحظه با قیمت بازار (کارمزد بیشتر و لغزش). |
| **تریگر / Confirm** | تریگر: ورود وقتی قیمت به عدد رسید. Confirm: ورود بعد از تأیید (مثلاً بسته شدن کندل ۴ ساعته پشت سطح). |
| **ریسک‌فری** | آوردن استاپ به نقطه‌ی ورود تا باقی پوزیشن ضرر ندهد. |
| **سیو سود / پله‌ای** | بستن بخشی از حجم روی هر تارگت. |
| **فاندینگ** | پرداخت دوره‌ای (هر ۸ ساعت) بین لانگ‌ها و شورت‌ها در فیوچرز. |
| **مارک پرایس** | قیمت مرجع صرافی برای لیکوئید (نه آخرین معامله). |
| **امتیاز / ستاره** | امتیاز (۰ تا ۱۰۰) احتمال موفقیت از نظر مدل؛ ستاره (۰ تا ۵) اینکه سابقه‌ی همین نوع سیگنال در گذشته چقدر مطمئن بوده. |
| **افق** | مدت نگه‌داشتن معامله‌های رادار (کوتاه ۲۴ ساعت، بلند ۳ روز، هفتگی ۷ روز). |
| **دیرهنگام** | سیگنالی که تارگت اولش پیش از انتشار خورده بود؛ پیش‌فرض در آمار کانال نمی‌آید. |
| **ضریب سود** | جمع سودها ÷ جمع ضررها. بالای ۱ یعنی سودده. |

## ۱۸. عیب‌یابی و پرسش‌های رایج

**کانال باز نمی‌شود / «تلگرام: قطع».**
فیلترشکن را روشن کن یا واسط شخصی بساز (۳.۴). در «وضعیت و عیب‌یابی» ببین کدام واسط جواب می‌دهد.

**عکس پست‌ها نمی‌آید.**
لینک عکس‌های تلگرام موقت است؛ برنامه خودش تازه‌اش می‌کند. اگر نشد «دوباره» روی همان عکس، یا واسط شخصی.

**کانال‌سنج: «کندل نیامد».**
«آزمایش اتصال کندل» را بزن. اگر هیچ منبعی جواب نداد، فیلترشکن یا واسط را عوض کن، بعد «سنجیدن تازه‌ها و در جریان‌ها».

**کانال‌سنج: خیلی «در جریان» است.**
سیگنال‌های این کانال استاپ و تارگت دور دارند و طول می‌کشد. «سنجیدن تازه‌ها و در جریان‌ها» را بزن تا با قیمت امروز به‌روز شوند. اگر نخواستی صبر کنی، «بستن با قیمت الان» روی هر کدام، یا «مهلت نتیجه» را در قانون‌ها کم کن.

**کانال‌سنج: سیگنالی که می‌دانم سر وقت داده «فعال نشد» شده.**
روی ردیفش ببین قیمت لحظه‌ی انتشار چقدر با ورود فاصله داشت. «ورود همان لحظه» را بزن، یا در قانون‌ها «ورود به‌موقع: تحمل ۳٪ با قیمت بازار». برای پست‌های «ورود مجازه» در «اصلاح عددها» ورود را خالی بگذار.

**کانال‌سنج: بعد از اصلاح هنوز در «نیاز به بررسی» است.**
اگر ورود هنوز با قیمت بازار جور نیست، برگه همین را می‌گوید و عدد درست را پیشنهاد می‌کند. اگر یادآوری یک سیگنال قدیمی است، «پست نتیجه است» یا «با تاریخ اصلی بسنج».

**قیمت‌ها «قدیمی» است.**
یعنی از حافظه آمده و اتصال قیمت قطع است. ↻ بالای صفحه یا عوض کردن واسط.

**روی آیفون اعلان نمی‌آید.**
برنامه را از آیکون صفحه‌ی اصلی باز کن (نه از سافاری) و در تنظیمات اعلان گوشی را روشن کن. برای وقتی برنامه بسته است: هشدار تلگرام.

**نسخه‌ی تازه را نمی‌بینم.**
برنامه را ببند و دوباره باز کن، یا «نسخه‌ی تازه» را بزن.

**می‌خواهم یک بخش را نبینم.**
تنظیمات › امکانات › کلیدش را خاموش کن.

## ۱۹. برای توسعه‌دهنده

### ساختار

- `index.html` ریشه‌ی مخزن **ساخته می‌شود**؛ دستی ویرایشش نکن. منبع در `src/` است:
  - `src/index.html` پوسته (نشانه‌های `/*@css*/` و `//@js`)،
  - `src/css/*.css` استایل‌ها به ترتیب نام،
  - `src/js/*.js` اسکریپت‌ها به ترتیب نام؛ همه در یک `<script>` کنار هم قرار می‌گیرند (ماژول نیستند، تابع‌ها مشترک‌اند).
- `proxy/worker.js` ورکر کلودفلر (واسط، همگام‌سازی، هشدار تلگرام)؛ `proxy/tg.php` واسط PHP.
- `sw.js` سرویس‌ورکر (فقط فایل‌های خود برنامه را نگه می‌دارد)؛ `manifest.webmanifest` برای نصب.

### ساخت و تست

```bash
node tools/build.js           # src/ ← index.html
node tools/build.js --check   # فقط بررسی (CI همین را اجرا می‌کند)

npm install && npx playwright install chromium   # یک بار
npm test                      # همه‌ی تست‌ها (Playwright، بی اینترنت؛ شبکه ساختگی است)
bash tests/run.sh audnow gate # فقط چندتا
FULL=1 npm test               # همراه خزنده‌ی کامل
```

- هر تست `tests/<نام>.test.js` برنامه را در کروم باز می‌کند؛ داده‌ی ساختگی از `tests/fixture.js`.
- گزارش‌ها: `/tmp/signaldesk-tests/logs/<نام>.log`.
- با هر push، GitHub Actions (`.github/workflows/tests.yml`) ساخت را چک و تست‌ها را اجرا می‌کند.

### قراردادها

- تغییر در `src/`، بعد `node tools/build.js`، و هر دو (`src/` و `index.html`) کامیت شوند.
- هر امکان تازه یک ردیف در `docs/features.md` و یک تست.
- بعد از تغییر `proxy/worker.js`، ورکر باید دوباره Deploy شود.
- کارهای منتظر تصمیم: `docs/backlog.md` و `docs/club-plan.md` (تا تصمیم گرفته نشده اجرا نمی‌شوند).
