# تست‌ها

هر فایل `*.test.js` یک تست مستقل با Playwright است که برنامه را در کروم باز می‌کند؛ درخواست‌های
شبکه (تلگرام، صرافی‌ها، ورکر) با داده‌ی ساختگی جواب داده می‌شوند، پس اینترنت لازم نیست.
`worker.test.mjs` کد ورکر کلودفلر (همگام‌سازی و هشدار تلگرام) را بدون مرورگر می‌سنجد.

```bash
npm install && npx playwright install chromium   # یک بار
npm test                          # همه (به‌جز خزنده‌ی کامل)
bash tests/run.sh autoexec gate   # فقط چندتا
FULL=1 npm test                   # همراه خزنده‌ای که روی همه‌ی دکمه‌ها کلیک می‌کند (چند دقیقه)
```

- اجراکننده خودش سرور ایستا را روی درگاه 8899 بالا می‌آورد.
- گزارش هر تست: `/tmp/signaldesk-tests/logs/<نام>.log`؛ عکس‌ها هم در همان پوشه.
- تست رد شده یعنی ❌ یا خطای صفحه (PAGEERROR) یا خروج با خطا.
- با هر push روی گیت‌هاب، همین‌ها در GitHub Actions اجرا می‌شوند (`.github/workflows/tests.yml`).

تست‌های `lessons`، `lock2`، `scan` و `tidy` نسخه‌ی قبل کنار گذاشته شدند: مال رابط کاربری قدیمی بودند
و روی همان نسخه هم رد می‌شدند؛ کارشان را تست‌های تازه‌تر (`guide`، `ledit`، `cats`، `backup`، `feat`) پوشش می‌دهند.
