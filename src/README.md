# کد برنامه

`index.html` ریشه‌ی مخزن **ساخته می‌شود**؛ دستی ویرایشش نکن. تغییر را اینجا بده و بساز:

```bash
node tools/build.js          # src/ → index.html
node tools/build.js --check  # فقط بررسی (CI همین را اجرا می‌کند)
```

- `index.html` — پوسته‌ی HTML (سربرگ، نماها، تنظیمات). نشانه‌ی `/*@css*/` و `//@js` جای کد است.
- `css/` — استایل‌ها به ترتیب نام.
- `js/` — اسکریپت به ترتیب نام؛ شماره‌ی اول نام ترتیب اجراست. همه در یک `<script>` کنار هم
  قرار می‌گیرند، پس تابع‌ها و متغیرها مثل قبل بین فایل‌ها مشترک‌اند (ماژول نیستند).
  هر فایل از یک سرفصل `/* ==================== … ==================== */` قبلی شروع می‌شود.
